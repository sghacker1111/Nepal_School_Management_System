# Routine profiles, percentage reports and catalog protection

Implemented in the isolated accounting-completion worktree, without touching the dirty original checkout or publishing these changes.

- Percentage reports: shared six-column component-row table in both individual and bulk routes; TH/PR full and obtained values under the Subject column; rowspan serial/total/remarks; nonapplicable components dashed and thematic assessments kept as overall rows. Percentage cards use a division key/result, not the GPA key or credit-hour note.
- Weekly profiles: manual/automatic modes, per-day counts and HH:MM times, optional short/tiffin breaks, assigned subject/teacher editing, initials and legend, multiple saved profiles, draft/activate separation, optimistic profile revisions, layout and slot history.
- Activation validates class-teacher first periods, subject/teacher scope, exact weekly allocations and teacher time overlaps across active classes. Failed operations roll back. Manual drafts can be incomplete; manual/automatic drafts can overlap other classes. Error recovery preserves bounded submitted editor values without replacing the read-only active preview.
- Catalog checks block normalized class aliases and duplicate class subjects by English/Nepali names or code. Class and subject creation/mapping is admin-only. School write locks cover duplicate check plus mutation.
- Targeted cleanup archives only a class named exactly `7` in the school containing teacher `sgsunil`, after admin password and checkbox confirmation. No linked students, marks, invoices, sections or history are deleted.
